# 東北賞楓自駕 2026

2026/11/1–11/7 東北紅葉自駕的家庭旅遊網站。

## 怎麼改內容

網站的內容都來自 Google 試算表裡「🌐」開頭的分頁，改那幾個分頁、重新整理網頁就會更新：

| 分頁 | 網頁上的位置 |
|---|---|
| 🌐設定 | 封面標題、日期、公告 |
| 🌐每日 | 行程頁每一天的標題、路線、住宿、開車時間 |
| 🌐行程 | 行程頁每一天的時間軸 |
| 🌐住宿 | 住宿頁 |
| 🌐交通 | 交通頁（航班、租車、車程） |
| 🌐景點 | 景點頁 |
| 🌐清單 | 準備頁的勾選清單（人名欄可以改，大家在網頁上勾會寫回這裡） |
| 🌐連結 | 準備頁下方的實用連結 |

注意：第一列的欄位名稱不要改，網頁靠它對應資料。新增一列就是新增一筆。

### 照片（🌐景點、🌐住宿 的「圖片」欄；🌐交通 的「租車／圖片」列）

一格可以放好幾張，一行一張，格式是 `網址 | 說明`（說明可省略）。在格子裡換行用 Ctrl+Enter（Mac 用 ⌘+Enter）。

- 放在網站裡的照片：檔案放進 `photos/` 資料夾，大圖叫 `名稱.jpg`（寬約 1600px）、縮圖叫 `名稱-s.jpg`（寬約 960px），格子裡寫 `photos/名稱.jpg | 說明` 就好（縮圖會自動對應）
- 自己拍的照片：上傳到 Google 雲端硬碟 → 共用設成「知道連結的任何人」→ 複製連結貼上即可
- 網路上的照片：用 Wikimedia Commons 等允許轉載的圖庫，說明裡註明攝影者和授權

### 地圖（🌐行程 的「座標」欄）

Google 地圖上對地點按右鍵（手機長按），點最上面的數字就會複製座標，貼到「座標」欄（格式 `緯度, 經度`）。
有座標的地點會出現在當天地圖上，起點自動用前一晚的住宿；類型是「可選擇」（或舊的「備案」）的地點只標示、不連路線；🌐景點 的「狀態」寫「可選擇」會歸到景點頁的「可選擇」分頁。
「地圖標籤」欄是簡易地圖上顯示的短名稱（例如「日光別墅」），沒填就用「項目」。

行程頁有兩種地圖：
- 簡易地圖（`trip-map.js` 畫的 SVG，縣界來自 `tohoku-map.js`）：最上面的「全程路線」可以點 Day 只亮那天的路線；每天的卡片裡也有一張
- Google 地圖：在每天的卡片裡切換。`config.js` 填了 `GOOGLE_MAPS_EMBED_KEY` 會用官方嵌入（手機上最穩定），沒填用舊版免金鑰嵌入

### 導航（🌐交通 的車程列）

「導航／圖片」欄填目的地（Google 地圖搜得到的名稱），網頁上點那段路線就會從目前位置導航過去。

其他分頁（訂單、價格等）不會出現在網站上。

## 檔案

- `index.html`、`style.css`、`app.js`：網頁本身
- `config.js`：Apps Script 網址
- `data.json`：試算表連不上時用的備份資料
- `apps-script/Code.gs`：貼到試算表的 Apps Script
